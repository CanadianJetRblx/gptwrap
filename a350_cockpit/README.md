# Airbus A350-900 flight deck (Blender)

A procedural Blender model of the A350-900 cockpit. Everything is generated by
three Python scripts, so any dimension or panel layout can be corrected in one
place and the whole model rebuilt.

| File | What it is |
| --- | --- |
| `a350_900_cockpit.blend` | The built scene (Blender 5.x, textures packed, 8 cameras) |
| `build_cockpit.py` | Geometry, materials, lighting, cameras, rendering |
| `panels.py` | Every control panel: face-plate legends plus the 3D position of each knob, key, push-button, guard and toggle |
| `displays.py` | Symbology shown on the six large displays and the two standby units |
| `renders/` | Reference renders from each camera |

## Rebuild

```
pip install bpy pillow            # or use Blender's own Python
python3 build_cockpit.py          # writes a350_900_cockpit.blend
python3 build_cockpit.py --render # also renders every camera into renders/
python3 build_cockpit.py --preview --render --views panel,pedestal
```

With a normal Blender install: `blender -b -P build_cockpit.py -- --render`.

## Conventions

- Units are metres, +X is the F/O side, +Y is forward, +Z is up.
- The origin is on the centreline at floor level, at the pilots' eye station
  (eyes at X = ±0.53, Y = 0, Z = 1.22).
- Collections: `Structure`, `MainPanel`, `Glareshield`, `Pedestal`, `Overhead`,
  `Seats`, `SideConsoles`, `Lights`, `Cameras`.

## What is modelled

- Shell with the six flight-deck windows (two windshields, two side windows per
  side), centre post with standby compass, lining, floor, door, ceiling pods.
- Main instrument panel: five 15.4 in display units (the two outer OIS displays
  angled in toward the pilots), the switching column (AIR DATA / FMS) and the
  brake / landing-gear column with the gear lever.
- Glareshield: raised centre block with the AFS control panel, both EFIS
  control panels and MASTER WARN / CAUT, and the lower wings with side-stick
  priority, CHRONO and loudspeaker controls.
- Pedestal: lower centre display flanked by the two standby instrument units,
  both KCCUs with palm rests, thrust levers, RMP 1/2/3, engine masters and
  start selector, ECAM control panel, speed brake and flap levers, TCAS panel,
  park brake, accumulator gauge, pitch and rudder trim, L/G gravity extension,
  cockpit lighting, cockpit door switch, printer, handset.
- Overhead: three columns (centre plus two canted side columns) with every
  push-button, guard, toggle and knob as separate relief.
- Two pilot seats, third-occupant seat, side consoles with side-sticks on their
  stepped boots, tillers, loudspeaker grilles, stowage, rudder pedals, stowed
  sliding tables.

## Accuracy

Layout, control order and proportions were taken from photographs of real
A350-900 and A350-1000 flight decks (list below). Metric scale comes from
hardware with known sizes: the 15.4 in 16:10 displays (332 × 207 mm active
area), the 146 mm pedestal module width and standard push-button sizes; other
dimensions were measured off the photographs relative to those.

Airbus does not publish dimensioned flight-deck drawings, so this is a
photo-matched model, not a CAD-exact one. Expect panel positions to be right
to roughly a centimetre or two and the shell (window outlines, lining, ceiling)
to be the loosest part. Known limits:

- The aft third of the overhead panel (flight controls, ADIRS, reset panels,
  fuel and hydraulic rows) was only visible at low resolution, so its control
  order follows Airbus family convention rather than a clear photograph.
- Seats, side consoles and the cockpit shell are simplified forms.
- The optional head-up displays are not fitted.
- Small legends are legible in close-up renders but are approximations of the
  real engraving.
